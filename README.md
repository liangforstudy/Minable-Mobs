# Minable Mobs

From that one thumbnail from that one specific Dream video.

https://www.youtube.com/results?search_query=this+cursed+minecraft+video+will+trigger+you

## Features

<!-- Screenshot thumbnails coming soon -->

- **Mine any mob like a block.** Hold attack with a stone or better pickaxe and dig right through it.
- **Mine players too.** Respects PvP and teams, and they die with "X was mined by Y".
- **Tap to hit, hold to mine.** A quick click still attacks normally.
- **Per-mob break times.** Make a zombie as hard as stone or as soft as wood, in the settings screen (Mod Menu or `/minemobs settings`).

## How to install

Grab the latest jar from the [Releases page](https://github.com/liangforstudy/Minable-Mobs/releases) and drop it in your `mods` folder along with [Fabric API](https://modrinth.com/mod/fabric-api).

Requires Fabric for Minecraft 1.21 / 1.21.1. [Mod Menu](https://modrinth.com/mod/modmenu) is optional.
